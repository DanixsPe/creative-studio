# Creative Studio

Aplicación web personal/educativa para gestionar marcas y preparar generaciones de contenido con IA.

V0.1 incluye el workspace, múltiples marcas locales, prompt, recursos e inspiración, tipo de diseño y cantidades 4/6/9/12/24.

Stack: Next.js + React + TypeScript + Tailwind + Supabase + Vercel.
